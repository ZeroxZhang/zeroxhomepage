# raw/ — 原始参考资料

本目录用于**手动放入**未经整理的参考资料：格式不限（md、pdf、网页存档、截图、源文件等），命名不做强制要求。

## 用途

- 撰写正式文档（PRD、调研结论、设计规范等）时的素材来源
- 开发过程中的参考（旧站内容备份、灵感站点、动效样例、外部文档等）

## 约定

1. **本目录不强制命名与格式规范** —— 与 `docs/` 其他子目录不同，这里故意保持松散，怎么顺手怎么放
2. **只读原则**：AI 引用本目录内容时保持原样，不重新格式化、不重命名、不删除
3. **正式结论不放在这里**：加工后的产出写入对应的正式子目录（`research/`、`prd/` 等），并在文中注明引用了 `raw/` 中的哪些文件
