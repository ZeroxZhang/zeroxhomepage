# design/ - 设计方向

本目录记录跨页面有复用价值的体验原则、视觉语言、组件行为和动效方向。探索草案与已采用方向可以并存，但应能看出各自状态。

## 原则

- 设计文档给实现提供共同方向，不替代原型、真实内容和浏览器验证。
- 区分体验目标、当前默认值和必须满足的边界；不要把每个像素或某次探索永久固化。
- 实现、可用性、性能或内容反馈可以推动设计调整。采用新方向时同步更新相关组件和文档。
- 无障碍、可读性和减少动态效果等用户需求属于设计质量边界，不作为可选装饰。

## 计划采用的方向

- 作品集子页面计划采用 [`docs/raw/zerox-dark-editorial.zip`](../raw/zerox-dark-editorial.zip) 中的设计风格与规范；该压缩包是后续设计和实现的原始参考。
