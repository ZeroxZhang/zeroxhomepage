## 1. 站点结构总览

```
zeroxzhang.cc
├── 首页 /                    （单页分区：英雄区 → 主导航 → 作品集模块区 → footer）
├── 关于 /about               （个人介绍页，三大板块之一）
├── 作品介绍页 /work/<slug>   （每作品一页，当前共 35 页）
└── 博客 /blog                （占位：结构待后续 brief 定义）
```

## 2. 首页（`/`）

首页为单页、自上而下的分区结构：

1. **英雄区**：首页视觉入口。
2. **主导航**：见第 3 节。
3. **作品集模块区**：按模块展示全部作品，每个作品一个模块卡片，卡片内容为**作品名 + 一句话定位 + 摘要 + 状态/分类 + 作品链接**（链接进入该作品的介绍页）。当前 35 个作品的正式数据源为 `content/works/`；首页按 `featured`、`weight` 与分类组织视觉层级，不在组件中复制文案。
4. **Footer 信息区**：见第 6 节。

## 4. 作品介绍页（`/work/<slug>`）

- 每作品一个独立介绍页，当前共 35 页；每个文件同时包含完整中文与英文版本，语言切换不改变作品 slug。
- 统一市场叙事层级：五秒价值承诺 → 用户高压场景 → 新方式与转变 → 结果型能力 → 低摩擦开始 → 信任/边界 → 主要 CTA。统一的是决策顺序，页面标题和模块密度按产品单独创作。
- `flagship`、`featured`、`standard`、`compact` 只控制内容和首页视觉权重，不取消任何作品的独立详情页。
- 作品页面必须区分公开实测、源码核验、私有快照和产品自述；原型、数据质量、隐私、金融/医疗边界等限制与能力同等重要。
- 截图、演示、架构图和视频作为扩展媒体，未来按 `docs/specs/2026-08-21-portfolio-content-model.md` 的预留字段接入。
