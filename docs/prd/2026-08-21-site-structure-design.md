## 1. 站点结构总览

```
zeroxzhang.cc
├── 首页 /                    （单页分区：英雄区 → 主导航 → 作品集模块区 → footer）
├── 关于 /about               （个人介绍页，三大板块之一）
├── 作品介绍页 /work/<slug>   （每作品一页，共 n 页）
└── 博客 /blog                （占位：结构待后续 brief 定义）
```

## 2. 首页（`/`）

首页为单页、自上而下的分区结构：

1. **英雄区**：首页视觉入口。
2. **主导航**：见第 3 节。
3. **作品集模块区**：按模块展示全部作品，每个作品一个模块卡片，卡片内容为**作品简介 + 作品链接**（链接进入该作品的介绍页）。作品清单与内容待后续 brief。
4. **Footer 信息区**：见第 6 节。

## 4. 作品介绍页（`/work/<slug>`）

- 每作品一个独立介绍页，路由用 slug 标识；slug 规则与页面数 n 待框架选型后由 `specs/` 定义。
- 通用模板（必选）：作品名、作品简介、作品链接（仓库/线上地址等）。
- 扩展位（待内容 brief 确认）：截图/演示等媒体区。

## 5. 关于页（`/about`）

- 结构占位：个人介绍主体区 + 扩展位；内容细节待内容 brief。
