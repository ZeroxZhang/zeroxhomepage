# user_original_briefs/ - 用户原始需求

本目录保存用户提供的阶段性说明、Prompt 和需求原文，用于追溯项目意图。它记录当时的输入，不等于所有内容永久有效。

## 使用方式

- 用户可以直接把复杂任务说明放在这里，也可以只在会话中提出需求；没有强制落盘流程。
- Agent 默认不改写用户原文。只有用户明确要求整理或修订该文件时才在原处编辑。
- 从 brief 得出的需求、设计或技术决定放入对应活跃文档，并在需要时链接原文。
- 新的用户方向可以补充或取代旧 brief。发生冲突时以最新明确意图为准，并更新受影响的活跃文档。
- 格式和命名由用户使用习惯决定。
