# user_original_briefs/ — 用户原始需求与 Brief

本目录存放**用户写给自己 Agent 的阶段性说明与需求原文**。`docs/` 下其他子目录放的是 AI 生成的正式文档，这里只放用户原文。

## 典型用法

- 阶段性的复杂任务：先把需求/说明写成一份 Prompt 文件放这里，再让 Agent 读该文件去干活
- 过程中的中间对话留在会话里即可，**不**落盘到本目录，也不单独成文件

## 约定

- Agent 对这些文件只读不改：引用保持原样，不重写、不总结
- 格式与命名不设要求，怎么顺手怎么来
- 这是需求源头：正式文档（`prd/`、`specs/` 等）的需求表述应能回溯到这里的原文
