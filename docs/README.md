# docs/ — 项目纲领性文档

本目录存放**辅助 AI 开发个人网站**的纲领性、长期性文档，是项目决策与规划的沉淀处。与 CLAUDE.md 定位一致：只保留长期重要信息，需随项目实时更新。

- **AI 会话入口**：根目录 `CLAUDE.md`（每个会话必读）
- **背景文档**：按主题进入本目录对应子目录

## 子目录结构

| 目录 | 用途 | 示例内容 |
|------|------|----------|
| `prd/` | 产品需求文档 | 站点需求、功能清单、页面结构定义 |
| `research/` | 调研结论 | 技术栈对比、动效方案调研、竞品分析 |
| `plans/` | 开发规划 | 里程碑、任务拆解、路线图 |
| `iterations/` | 版本迭代信息 | 版本记录、changelog、迭代复盘 |
| `design/` | 设计规范 | 设计系统、色彩/字体规范、动效规范 |
| `specs/` | 技术方案文档 | 动效系统、路由、数据管理等技术设计（"怎么做"） |
| `ideas/` | 想法池 | 功能点子、选题、灵感，随手记、零承诺 |
| `raw/` | 原始参考资料 | 手动放入的未整理素材，格式与命名不受约束 |
| `archive/` | 归档区 | 作废文档的存放处，仅归档不修改 |

以上子目录均已创建，各含一份用途说明（README.md）。

## 约定

1. **单一事实源**：同一主题的结论只保留一份最新文档；作废版本移入 `archive/` 或删除，不做多版本并存。
2. **实时更新**：与 CLAUDE.md 的维护规则一致——某项决策或事实变化时，在同一笔改动中更新对应文档并一起提交。
3. **文件命名**：`YYYY-MM-DD-<主题>.md`，主题用英文 kebab-case（如 `2026-08-19-tech-stack-comparison.md`）。`raw/` 不在此约束内。
4. **AI 参与开发时**：先读 `CLAUDE.md`，再按任务主题读取本目录相关文档；产出纲领性结论（决策、规范、规划）时写入本目录，不散落在会话中。
