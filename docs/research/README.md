# research/ - 调研与证据

本目录保存会影响项目判断的证据、比较、局限和建议。调研帮助决策，但不会仅凭存放在这里就成为强制方案。

## 原则

- 区分已核验事实、推断、建议与仍待验证的问题。
- 保留足以复查关键结论的来源；体量较大的原始材料可放在 `../raw/`。
- 研究范围和时效应与结论强度匹配。外部信息变化后，可以更新原文或用新研究明确取代旧判断。
- 产品决定应落到相应 PRD、design 或 spec，并链接研究依据；不要让调研文档同时承担所有后续规则。
- 调研方法按风险选择，不要求所有主题采用同一种报告结构。
