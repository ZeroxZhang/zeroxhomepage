01 / OVERVIEW

从「模型加工具」走到看得见的执行链

零件清单好记，却讲不清系统怎样运转；这门课把它拆成六章可操作的过程。

「Agent 等于模型加工具」能概括零件，却交代不了系统怎样运转。这门课要回答的问题更具体：一条消息从哪里进来、何时调用工具、结果如何回到上下文、错误又在哪一层暴露。

直接阅读源码时，这些关系散落在多个文件和抽象中。Nanobot Course 把 nanobot 的执行流拆成六章，通过动画、模拟和练习建立组件之间的因果关系，再把读者带回代码结构。

无需先安装框架或配置模型，从一次消息的移动开始，就能理解 Agent 的运转方式。

02.1 / Observe

把抽象组件改写为可观察的行为

数据流动画逐步移动消息包，架构图允许点击角色查看职责，群聊模拟把协调过程放进同一对话窗口。你看到的不是一排名词，而是组件之间的因果关系。

→
群聊协调过程同窗可见

三类观察式互动各自承担一个解释任务，让抽象关系变成可回放的行为。

02.2 / Practice

用练习把「看过」和「懂了」分开

拖拽匹配要求区分消息、模块与能力边界，选择题提供即时解释，Bug 挑战要求定位出错环节并判断修复方向。

每个互动都有明确的教学任务：先让读者做出预测，再看系统回应；判断错了，就回到对应解释重看。它不为装饰页面而设。

练习服务于真实误解：让「看过代码」和「理解调用关系」能被区分。
