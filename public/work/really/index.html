01 / OVERVIEW

把难题拆开，再决定该怎么问

直接给建议，常常只把表面提问改顺，却留下隐含前提和相互冲突的原因。

「怎么提高转化？」「要不要离职？」「团队为什么总在同一个地方争论？」——这类问题往往同时装着事实、情绪、身份、资源与制度约束。若急着给建议，答案很容易只优化一句表面提问，却把隐含前提和相互冲突的原因留在原处。

Really 是一个跨学科深度询问 Agent Skill。它先把输入拆成现象、结构和假设，再从多个学科角度寻找能够解释更多现象的成因，最后重写问题并生成一份完整分析报告。

它不急着给建议：分析停在需要你选择的地方，价值取舍与最终行动始终回到你手上。
