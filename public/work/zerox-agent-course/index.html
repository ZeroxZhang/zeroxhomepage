01 / OVERVIEW

先从目录树里走出来，换成一张运行地图

大型 Agent 仓库名词很多，却说不清消息经过了谁、在哪里暂停、失败后如何恢复。

大型桌面 Agent 仓库同时包含界面进程、后台服务、模型适配器、工具执行、权限判断和持久化。从目录树开始，名词很多，却说不清消息经过了谁、在哪里暂停、失败后如何恢复。

若阅读从目录树或入口文件开始，很快会遇到大量名词，却仍说不清用户按下回车后，消息经过了谁、在哪里暂停、失败后如何恢复。Zerox Agent Course 是一门浏览器内运行的中文互动源码课：它以一次任务的生命周期为主线，把 Zerox Agent 的界面、Electron 进程边界、Agent Loop、授权、扩展能力和存储恢复串成一张运行地图，再把每个概念带回具体文件与代码片段。

直接交付的是一套可以反复浏览的系统心智模型：谁持有状态、谁能执行工具、审批在哪发生、恢复依赖哪些记录。每个模块都可以独立返回重看，单页结构也便于在分享讨论时指向同一套上下文。

它不是把架构压成一张静态总览，而是让「看过代码」和「理解调用关系」能够被区分。Reading Map

02 / MODULES

六个模块，按理解依赖逐层展开

从认识 Zerox Agent 到存储恢复，每章都建立在前一章的理解之上。

课程从「认识 Zerox Agent」和消息全链路开始，随后介绍 Electron 三层角色、Preload 白名单与依赖注入装配。第三模块进入 Think—Act—Observe 循环、统一模型接口和上下文压缩；第四模块聚焦 Shell 命令分析、Permission Engine、审批与 Goal Mode。最后两章覆盖内置工具、Skill、MCP、子智能体，以及 JSON/JSONL、SQLite、Checkpoint、事件总线和执行轨迹。

Six Modules / 依赖顺序M01 → M06
M01认识 + 消息链路 → M02Electron 三层 + Preload → M03Think—Act—Observe → M04Permission Engine + 审批 → M05工具 · Skill · MCP → M06JSON · SQLite · 轨迹
02.1 / Interactive Forms

互动不是装饰，是把「看过」和「理解」分开

可步进的数据流动画显示消息如何移动，角色扮演式聊天展示模块协作，架构组件可点击查看职责。这些互动把抽象的组件关系变成可以一步步观察的行为。

02.2 / Exercises

在继续之前，先做出判断

选择题、拖拽匹配、权限漏洞挑战和结业测验要求读者在继续前作出判断。练习服务于真实的误解，不承担装饰页面的任务，因此「看过代码」和「理解调用关系」能够被区分。

每个模块都可以独立返回重看——遇到薄弱点，回到相应动画重放即可。
03 / WORKFLOW

一条低摩擦的学习工作流

跟着消息走一遍，再用动画与练习把理解钉牢，最后回到源码核验。
Study Path / 学习路径4 Steps
01追踪一条消息 → 02按导航点推进 → 03操作动画 / 完成练习 → 04回到源码核验

打开在线课程后，先跟随第一章追踪一条消息，再用导航点按模块推进；遇到关键机制时操作动画或完成练习，最后带着页面给出的文件名与调用链回到源码核验。

课程由分模块 HTML、共享 CSS 与原生 JavaScript 构成，build.sh 将各章节组装成一个静态 index.html，无需安装 Electron 或启动 Zerox Agent 即可学习。

它适合第一次阅读 Agent 工程的开发者，也适合希望理解桌面 Agent 安全与可恢复设计的产品和技术人员。Who It's For
