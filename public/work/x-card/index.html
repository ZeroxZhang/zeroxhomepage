01 / OVERVIEW

把帖子视觉从平台界面里拆出来

适合制作引用卡、演示样稿或经授权的社交内容预览，不带走真实账号。

直接截取社交平台帖子，会把导航、推荐内容、压缩痕迹和真实账号信息一起带走。X Card 把帖子视觉从平台界面中拆出来，姓名、头像信息、正文、时间与视觉选项都由使用者明确填写。

它面向需要控制构图和隐私的单张文本内容。整页只做一件事：把一段文字排版成一张干净的 X 风格卡片，不需要登录真实账号。输入内容在浏览器本地参与排版，没有业务后端负责保存正文。

需要控制构图和隐私的单张内容，不必从真实账号截图开始。Privacy-first
02 / CAPABILITIES

从一张空白卡片到高清 PNG

编辑、排版、预览与导出在同一条路径里完成。
Compose Flow / 制作路径4 Steps
01编辑资料与正文 → 02选择主题与尺寸 → 03确认预览 → 04导出高清 PNG
Cap 01 / Compose

本地可控

先编辑资料与正文，再选择浅色或深色主题、边框和模拟认证标识；画布宽度可在 420—900px 之间调整，也能设置最小高度，正文支持重点加粗。

Cap 02 / Export

高清导出

确认预览后，按 2x 或 3x 清晰度导出 PNG，减少真实平台截图中的导航、推荐与压缩痕迹等无关元素。

Cap 03 / Stack

轻量实现

以原生 HTML、CSS 和 JavaScript 构建，部署在 GitHub Pages；输入内容在浏览器本地排版，无业务后端保存正文。

Boundary / 使用边界

模拟认证标识与可编辑资料不应被用于伪造真实发言；成品应根据发布语境标注为设计稿、引用卡或重制内容。
