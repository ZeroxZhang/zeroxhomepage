01 / OVERVIEW

从一段话到一张干净的卡片

短句、摘录和临时想法需要清楚排版与快速导出；过多模板与装饰反而延长一次简单分享。

短句、摘录和临时想法需要的是清楚排版与快速导出，过多模板和装饰选择反而会延长一次简单分享。Minimalism Note Card Generator 把流程收窄为四个元素，让内容保持页面中心。

填写昵称与正文后，页面识别中文或英文，并采用相应的字体与排版规则。你不需要在几十套模板里反复挑选，只需要把注意力放在文字本身。

卡片效果在页面中即可检查，随后可以复制内容，或通过 html2canvas 下载 PNG——一条足够短的制作路径。

把一次简单分享，收窄为文字、署名、主题和导出四个动作，而不是一长串装饰性决定。Four Elements

02 / CAPABILITIES

排版跟随语言，导出交给浏览器

两类关键设计：输入之后排版自动跟随语言；正文在浏览器客户端完成排版与导出。
02.1 / Typography Follows Language

输入之后，排版自动跟随语言

填写昵称与正文后，页面识别中文或英文，并采用相应的字体与排版规则。浅色、深色和暖色三套主题提供足够明确的气质差异，同时避免复杂图层。

主题只负责气质，不增加装饰层级——内容仍然是卡片里唯一的主角。

中文与英文采用不同的字体与排版规则；三套主题再提供气质差异。

排版规则跟随语言自动切换，使用者不需要手动为每一种文字调整字号与行距。
02.2 / Browser-side Export

浏览器承担主要工作

产品以 HTML、CSS 和 JavaScript 构建，正文在浏览器客户端参与排版和导出，没有业务后端保存输入内容。界面语言可在中文与英文之间切换，选择会写入 localStorage。

这一结构适合临时文字、社交分享和无需账号的快速制作：你可以在页面中检查卡片效果，再复制内容或通过 html2canvas 下载 PNG。

没有账号门槛，也没有业务后端保存正文——输入的内容只在你自己的浏览器里参与排版。
