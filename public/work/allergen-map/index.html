01 / OVERVIEW

先选地区，再读过敏原信息

全国健康资料常是一张长表；这张地图把阅读顺序调换过来。

全国性健康资料通常从一张长表或一组分类开始，普通读者还要先找出和所在地区有关的部分。过敏原地图调换阅读顺序：先在中国地图上选择地区，再进入吸入性、食物与接触类信息。

这是一个信息架构与交互呈现原型：验证地图、地区详情、分类面板和数据表怎样协同工作。它不提供经过验证的地区风险数据，也不承担诊断功能。

观察空间入口能否降低浏览成本，是这一原型最想回答的问题——先选地区，再读内容，而不是先读内容，再翻找地区。

它适合讨论地图如何改变健康信息的阅读顺序，也可作为数据接入前的交互验证载体。Information Architecture

02 / CAPABILITIES

地图、详情面板与文字入口

同一套界面里的几条入口，让地区信息不用靠手动搜索。
02.1 / Map to Detail

从全国视图进入地区详情

地图支持地区悬停与点击交互：颜色图例表达界面中的相对强度，详情面板按类型列出相关项目和说明。用户可以在全国概览与单个地区之间往返，无需在一份完整资料中手动搜索地名。

02.2 / Categories & Table

三类信息，与不依赖地图的文字入口

详情面板按类型列出吸入性、食物与接触类项目与说明；地区表格提供不依赖地图操作的文字入口，让用户即使不操作地图，也能从文字列表进入单个地区。

整体实现部署为静态单页，适合验证阅读路径和展示形式。

切换时的轻量动效提示当前选择和层级变化，不改变数据本身。

一次地区浏览的四步

从全国概览到单个地区，路径很短；打开网页即可开始。
