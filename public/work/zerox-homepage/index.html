01 / OVERVIEW

从当下入口，变成一份可以被翻阅的时间档案

从 2018 年开始，这套主页与博客持续连接公开身份、社交账号和长文内容。

个人网站既是当下入口，也会逐渐成为时间档案：它们记录了早期视觉偏好、关注主题与发布方式。

旧主页以极简门户连接 Blog、GitHub、Instagram 与小红书，矩阵画布和鼠标轨迹构成主要视觉识别；博客保存数字营销、数据分析和产品运营等长期文章。访客可以从轻量身份页进入更完整的内容记录。

这两套页面也是新网站重建时需要继承和重新整理的内容基础——哪些公开链接与内容应被继承，哪些交互和失效代码应停止沿用，都要从这里交代清楚。

02.2 / Two Systems

仍可访问，但不再代表当前技术方向

主页运行在 GitHub Pages，以静态 HTML 与 JavaScript 为主；博客采用 GitBook / Next.js 体系。两者在视觉、导航与部署上长期分离。

主页还保留了固定桌面布局、过时版权年份和偏重鼠标输入的交互。截至 2026-08-21，主页与博客均可公开访问，但更适合作为历史档案，不是新站的技术基线。

公开可访问不等于技术方向：这套旧站的价值在于被保存，而不是被照搬。
