01 / OVERVIEW

把买入前的判断，从脑子里写到纸面上

很多交易错误发生在分析开始之前；这个工具把那些基础判断变成一条可回看的记录。

不少交易错误发生在分析开始之前：买入理由只存在于脑中，仓位没有和风险承受能力对应，信息来源未经核对，风险线与放弃条件等到价格下跌后才临时决定。

市场工具通常继续增加行情与指标，却很少要求用户把这些基础判断写清楚。Invest Signal Kit 是一个在本地运行的 A 股与国内场内 ETF 决策检查工具，提供买前检查与持仓体检两条路径。

它通过结构化问题记录行动依据，并在下单或继续持有之前指出可见的风险缺口。工具不产生推荐标的，也不尝试预测价格。

检查单不能消除损失，但可以减少理由漂移和无意中扩大风险。Core Principle

02 / CAPABILITIES

买前检查、持仓体检与本地运行

两条路径各司其职，加上一条明确的隐私边界。
02.1 / Pre-trade Check

买前检查：把冲动转换成可阅读的记录

流程要求填写标的、计划金额、可承受风险、入场理由和信息来源。系统据此检查单笔仓位占比、单一持仓集中风险、理由完整性和风险边界。提示的用途是迫使决策者重新阅读自己的判断，而不是用另一个综合分数替代判断。

一次检查可能得到「继续补充来源」「降低金额」或「先不行动」等结论。历史最多保存最近 20 条检查的结论、风险线、下一步与关键原因，而不是完整表单和全部原始理由。

02.2 / Holding Review

持仓体检：检查最初的理由是否仍成立

流程关注当前亏损、单一持仓占比、预设风险线和继续持有的理由。用户在同一次体检中分别填写原始理由与当前理由，系统据此提示理由漂移。

它不会自动从历史记录恢复并比对完整原始表单——买前与持仓共享同一套原则：记录可核对的信息，暴露未回答的问题，再由人作出决策。

Local & Privacy / 本地运行与隐私

前端历史保存在浏览器 localStorage，本地 Python 服务仅使用标准库运行；默认路径不要求远程账户，也不需要把持仓数据上传到项目方服务器。

清除站点数据可能同时删除本地历史；设备、浏览器资料与备份仍需用户自行保护。

Boundary / 适用范围与风险

Invest Signal Kit 不接入券商，不自动执行交易，不评估个人全部财务状况，也不提供投资建议。输出取决于用户输入，遗漏或粉饰理由会直接降低检查价值。

市场风险、滑点和突发事件仍由使用者承担。
