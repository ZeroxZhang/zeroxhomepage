# content/ - 网站内容源

本目录保存网站面向访客的正式内容。默认让内容独立于组件、布局和动效，以便不同页面和未来实现复用；当更丰富的内容模型确有价值时，也可以通过明确的 schema 演进。

## 目录

- [`works/`](./works/)：作品列表信息、详情页正文与作品索引。

## 原则

- 展示文案在这里维护，事实依据和方案讨论留在 `docs/`，组件不要再复制一份可编辑文案。
- 内容格式应保持可读、可校验，并尽量不依赖单一前端框架。
- 事实、链接、语言版本和公开边界应彼此一致；涉及易变信息时保留核验时间或来源。
- 媒体文件放在公开资源目录，内容记录稳定引用和必要的替代文本。
- 局部 schema 是当前协作契约，不是永久模型。需要改变时，同时调整内容、加载器、校验和对应 spec。

具体作品约定见 [`works/README.md`](./works/README.md)。
