# Consulting Report Forge

把复杂业务问题，写成有依据的判断。

研究、建模、故事线与视觉报告贯通，交付可离线阅读的 HTML 和同版 PDF。

![真实历史成稿：TikTok 商业化报告选页，保留原始数据期间与来源。](/work-assets/2026-projects/forge-overview.png)

## 先回答问题，再组织页面。

市场是否值得进入、收入增长为何没有变成利润、多个方向如何排序？Forge 从业务问题与决策约束开始，选择分析框架，查找证据、保留计算，再形成能够逐页追问的论证。

### 研究与分析

核对来源、时期和口径；按问题选择市场测算、单位经济或情景分析。

### 形成故事线

让每一页承担一个明确任务，让标题、证据和限制相互对应。

### 制稿与复核

编译成稿，检查实际 HTML/PDF；复杂判断安排独立实例复核。

## 报告不仅要成形，也要经得起阅读。

实际成稿与布局工作台展示了两种能力：解释复杂证据，以及安排足够清楚的阅读层级。每个图表的来源、期间与限定需要继续保留。

![2026-09-25 AI 生物制药研究成稿选页：展示市场口径，不作为当前市场结论。](/work-assets/2026-projects/forge-market.png)

![真实 Layout Atlas 工作台截图：布局与容量视图。](/work-assets/2026-projects/forge-layouts.png)

## 材料更新后，知道哪些地方需要重查。

持久执行清单记录任务与恢复线索。内容和展示值变化会影响原审查的有效性；局部排版修订按证据确定重审页。模块填充检查同时关注大块无功能留白、裁切和溢出。

## 从一份经营分析开始。

先安装完整技能和所需依赖，再提供材料、预算、业务口径与停止条件。完整制作通常需要 Node.js、Python、浏览器和 PDF 检查工具。

### 示例任务

使用 zerox-consulting-report-forge 制作经营分析报告。读者为经营团队，回答未来两个季度应优先投入哪些渠道；保留来源、假设与计算，交付中文 HTML + 同版 PDF。

## 独立作品，持续在合集里维护。

原 consulting-report-forge 仓库保留历史版本；当前技能名为 zerox-consulting-report-forge。它交付 HTML/PDF，不输出可编辑 PPTX，也没有独立在线编辑器。质量取决于材料、模型和实际复核，不承诺固定时间或普遍提速。

# Consulting Report Forge

Turn business questions into evidence-backed decisions.

Connect research, modeling and narrative in an offline HTML report with a matching PDF.

![Historical output: selected TikTok monetization report pages, retaining original periods and sources.](/work-assets/2026-projects/forge-overview.png)

## Answer the question before composing the pages.

Should we enter this market? Why is revenue growth not becoming profit? Which option deserves investment? Forge starts with the decision and constraints, selects analytical methods, collects evidence and retains calculations before composing the report.

### Research and analysis

Check sources, periods and definitions; use market sizing, unit economics or scenarios as appropriate.

### Build the narrative

Give each page a purpose and align its claim, evidence and limitations.

### Produce and review

Compile the report and inspect actual HTML/PDF output; use an independent agent for complex judgments.

## Reports need to survive close reading.

The report sample and layout workbench demonstrate evidence presentation and readable hierarchy. Each chart retains its sources, time periods and qualifications.

![A page from the September 25, 2026 AI biopharma report: historical scope illustration, not a current market conclusion.](/work-assets/2026-projects/forge-market.png)

![Actual Layout Atlas workbench screenshot showing layout and capacity views.](/work-assets/2026-projects/forge-layouts.png)

## Know what needs review after a revision.

A persistent checklist records progress and recovery context. Changes to content and displayed values affect review validity; local layout changes identify the pages that need reinspection. Module checks flag unused whitespace, clipping and overflow.

## Start with an operating review.

Install the complete skill and runtime dependencies, then provide materials, budget, business definitions and stop conditions. The full workflow generally requires Node.js, Python, a browser and PDF inspection tools.

### Example brief

Use zerox-consulting-report-forge to recommend channel priorities for the next two quarters. Retain sources, assumptions and calculations; deliver an English HTML report and matching PDF.

## An independent work, maintained in the collection.

The original consulting-report-forge repository preserves historical releases. The current skill is zerox-consulting-report-forge. It delivers HTML/PDF, not editable PPTX, and has no standalone online editor. Quality depends on materials, models and actual review; no fixed completion time or universal speedup is claimed.
